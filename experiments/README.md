# Stock Prediction Experiments

This folder contains experiments with different machine learning models for stock prediction.

## Models

- **Simple Linear Regression** – Predicts outcomes using one feature.
- **Multiple Linear Regression** – Uses multiple features to make predictions.
- **Polynomial Regression** – Models nonlinear relationships.
- **L1 and L2 Regularization** – Explores techniques to reduce overfitting.
- **Random Forest** – Uses an ensemble of decision trees to make predictions.
- **XGBoost** – Uses gradient boosting to build an ensemble of decision trees.

## Purpose

These experiments helped me explore different machine learning techniques and compare approaches to stock prediction before developing my LSTM model.

Each model has different strengths and limitations, and its performance depends on the data, features, and evaluation methods used.

## Requirements

To run these models, download the historical NVIDIA (NVDA) stock dataset used by the notebooks.

**Note:** Make sure the dataset filename matches the filename referenced in the code. If necessary, rename the downloaded file so the code can locate and load it successfully.
